# Phase 0 — ACP log analysis directory

`../ACP_LOG.md` is the canonical raw capture.

This directory is intentionally additive. Generated `parts/` contain complete top-level JSON events only; never split an ACP event by line count.

Suggested analysis groups:

- `parts/` — deterministic event chunks generated by `scripts/split-acp-logs.py`.
- baseline handshake/session/tool scenarios.
- failures carried into Phase 1.
