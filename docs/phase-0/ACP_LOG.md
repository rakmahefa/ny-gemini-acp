# Phase 0 — ACP Log

This file stores raw ACP evidence captured from real Zed runs for the Phase 0 prompt matrix.

## Recording rules

- Paste the relevant ACP log excerpt after each test run.
- Keep the exact order of requests, responses, notifications, and stderr entries.
- Redact secrets, cookies, tokens, API keys, and private payloads.
- Include the prompt ID, date, Zed version, agent commit, session ID, and result status outside the raw block.
- Do not treat this file as a derived summary; the baseline interpretation belongs in `ZED_BASELINE.md`.
